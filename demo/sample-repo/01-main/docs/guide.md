# Guide

## Tags

Give a note tags when you add it. Tags are lowercase words without spaces.

## Lists

`store.list()` returns notes in the order they were added. Use `byDay` from
`format.ts` to group them by the day they were written.

## Limits

Titles over 80 characters are shortened in lists. Bodies are never cut.

## Backups

The notes file is plain JSON. Copy it to back it up.
