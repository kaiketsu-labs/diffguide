field-notes 2.4

This release adds streaming export and a one-step importer for v1 notes.

Changes

  • Export notes as newline-delimited JSON with store.exportTo.
  • Imported v1 notes are tagged imported.
  • Titles that end in a space no longer show it before the ellipsis.
